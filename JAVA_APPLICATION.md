# Java Application in ShadowNet IDS

Java 17 serves as the foundational backend technology for ShadowNet IDS, leveraging Spring Boot 4.0.6 to create a robust, type-safe, and scalable intrusion detection system. The application follows a layered architecture with Spring Boot's `@SpringBootApplication` annotation enabling auto-configuration and dependency injection. JPA entities like `User`, `Alert`, and `TrafficLog` use annotations such as `@Entity` and `@Table` for object-relational mapping with MySQL, providing strong type safety and database optimization through indexing. Business logic is encapsulated in service classes (`AuthService`, `DetectionService`, `AlertService`) utilizing `@Service` and `@Transactional` annotations for transaction management and data consistency. REST controllers handle HTTP requests with `@RestController` and `@RequestMapping` annotations, enabling automatic JSON serialization and flexible HTTP responses through `ResponseEntity`. Security is implemented through custom filters like `JwtAuthenticationFilter` that extend `OncePerRequestFilter` for request interception, JWT validation, and security context management using Spring Security's thread-local `SecurityContextHolder`. Advanced Java features include `ConcurrentHashMap` for thread-safe DoS detection tracking, lambda expressions for functional data processing, and comprehensive exception handling with try-catch blocks. Password security uses BCrypt encryption through Spring Security's `PasswordEncoder`, while JWT tokens are generated and validated using the jjwt library with cryptographic signing. Role-based access control is enforced via `@PreAuthorize` annotations for method-level security. Database operations utilize Spring Data JPA repositories with derived query methods and `Optional` for null-safe operations. Performance optimization includes HikariCP connection pooling, in-memory caching with concurrent collections, and lazy loading through read-only transactions. The Maven build system manages dependencies including Spring Boot starters, MySQL connector, and JWT libraries, ensuring consistent versions and automated build lifecycles. Java's type safety, mature ecosystem, JVM optimization, and extensive security libraries make it ideal for implementing sophisticated security features like brute force detection, DoS prevention, and comprehensive traffic logging in this enterprise-grade security application.
